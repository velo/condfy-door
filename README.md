# Condfy Door

Android home-screen widget that opens my building's doors through the Condfy API,
without waiting for the official app to load its camera feed.

This repository exists to **host release APKs**. The source lives on a private Git
server; only the built, signed APKs are published here.

## Install with [Obtainium](https://github.com/ImranR98/Obtainium)

1. Obtainium → **Add App**
2. App Source URL: `https://github.com/velo/condfy-door`
3. Add — Obtainium picks up the latest release APK and tracks updates.

APKs are signed with a stable release key, so updates install over previous versions.
